# Retrace 0.2.0

First official source-build release of Retrace: Apple Find My item tracking and
location history through Home Assistant.

## Install

Add `https://github.com/hmmferreira/retrace#stable` in Home Assistant's app
repository settings and install **Retrace**. Start it, open its Web UI and follow
Setup. Stable uses the macOS provider, with explicit local component consent and
one Apple account flow. Passwords, verification codes and device unlock passcodes
are not saved. Approve the discovered Retrace integration when prompted.

The companion integration is available in this release via HACS/custom repository
`hmmferreira/retrace` (category Integration), tag `v0.2.0`. Existing compatible
Retrace companion installations can discover the new app; integration code updates
are a separate action and may require a Core restart.

Stable starts fresh. Edge stays separate, including sessions, selected items,
entities and history. Nothing is migrated or deleted. Disable the development
poller when you no longer need the side-by-side comparison.

## Included

- Guided Apple authentication, item-key recovery, item selection and per-item refresh.
- Independent asynchronous item polling, bounded queries and preserved report times.
- Native Home Assistant trackers/history and account/check status feedback.
- Private encrypted account/machine state, restricted native worker and controlled
  Apple HTTP destinations. Cold app backups keep state capture consistent.
- Pinned runtime sources/dependencies/base images, retained component notices and
  software inventory. Retention bounds old encrypted Mac machine generations.

## Distribution and known limitations

This release publishes source, not public container images or Apple binaries.
Home Assistant builds it locally. On explicit opt-in, the app acquires the pinned
CoreADI component directly from Apple. Apple's bundled EA1510 terms apply; the
project has not established permission for extracting/emulating that component
on Linux. Publication is the maintainer's informed decision, not Apple approval,
legal clearance or a waiver of third-party rights. See the native license review.
The project is independent of Apple and is not a security-audited product.

Only amd64 Home Assistant OS/Supervised is supported. Apple compatibility is
unofficial and may change. Reports can be sparse; manual refresh cannot force a
new AirTag sighting. Battery level, street address and historic backfill are not
provided. History follows Recorder retention. Real-world longevity, expiry and
additional recovery scenarios remain ongoing validation; no uptime guarantee.

The app acquires no account credentials through a third-party signing service.
Root, a compromised parent image or a decrypted complete backup can still expose
secrets; keys beside ciphertext do not protect against host compromise. Protect
backups and do not expose the internal API publicly.
