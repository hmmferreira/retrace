# Retrace 0.2.1

Fix the blocked desktop map preview by using Home Assistant's native map and
location history. The app no longer loads OpenStreetMap tiles or Leaflet scripts;
its existing no-referrer privacy policy stays enabled. Open the native map from
Items. For a location trail, add a Home Assistant Map card, choose this
installation's Retrace trackers and set Hours to show. Approve the discovered
integration in Devices & services first. Stable and Edge trackers stay separate.

Update Retrace in Home Assistant Apps, then reload the Web UI. Sessions, selected
items and recorded history are preserved. No companion integration change or
Home Assistant Core restart is required for this fix.

All 0.2.0 source-build/native-component terms and documented limits still apply.
No Apple binaries are distributed, and no authentication flow was changed.
